# Customer Behavior Prediction

Predict e-commerce customer churn from the Kaggle E-Commerce Customer Churn dataset using Pandas, Scikit-learn, XGBoost, FastAPI, and Streamlit.

## Project Overview

This project trains a production-style churn classifier for customer retention workflows. The pipeline handles null values, one-hot encodes categorical columns, scales numeric columns, compares Logistic Regression, Random Forest, and XGBoost, then persists the selected XGBoost model for API and dashboard inference.

The Kaggle dataset usually contains fields such as `Tenure`, `PreferredLoginDevice`, `CityTier`, `WarehouseToHome`, `PreferredPaymentMode`, `Gender`, `HourSpendOnApp`, `NumberOfDeviceRegistered`, `PreferedOrderCat`, `SatisfactionScore`, `MaritalStatus`, `NumberOfAddress`, `Complain`, `OrderAmountHikeFromlastYear`, `CouponUsed`, `OrderCount`, `DaySinceLastOrder`, `CashbackAmount`, and the target column `Churn`.

## Setup

```bash
cd customer-behavior-prediction
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

Download the Kaggle E-Commerce Customer Churn dataset and save the full CSV as:

```text
data/ecommerce_churn.csv
```

The committed CSV is a tiny schema-compatible sample so the repository is runnable immediately. Replace it with the full Kaggle dataset before training for real model results.

## Train And Evaluate

```bash
python src/preprocess.py
python src/train.py
python src/evaluate.py
```

Training compares:

- Logistic Regression with class balancing
- Random Forest with randomized hyperparameter search
- XGBoost with randomized hyperparameter search and positive-class weighting

Artifacts generated by training:

- `models/xgboost_model.pkl`
- `models/preprocessor.pkl`
- `models/feature_columns.pkl`
- `models/model_results.json`
- `reports/evaluation_metrics.json`
- `reports/figures/confusion_matrix.png`
- `reports/figures/feature_importance.png`

On the full Kaggle dataset, the target operating point is F1 > 0.85 using XGBoost. Actual metrics depend on the exact data version and split; run `python src/evaluate.py` after training to write final results.

## Deployment

### Render API

1. Push this folder to GitHub.
2. Create a Render Web Service.
3. Use Python as the runtime.
4. Set the build command:

```bash
pip install -r requirements.txt
```

5. Set the start command:

```bash
uvicorn app.main:app --host 0.0.0.0 --port $PORT
```

6. Include the trained `models/xgboost_model.pkl`, `models/preprocessor.pkl`, and `models/feature_columns.pkl` artifacts or configure a private artifact download during build.

### Streamlit Cloud

1. Push the repository to GitHub.
2. Create a Streamlit Cloud app.
3. Set the app file to `streamlit_app.py`.
4. Add trained model artifacts to the repository or load them from secure cloud storage.

Live demo link: not published from this local workspace yet. After deployment, use the Render service URL for the API and the Streamlit Cloud app URL for the dashboard.

## Production Notes

- Keep the training dataset versioned outside Git when it contains private customer data.
- Validate API payloads at the edge and monitor missing-field rates.
- Retrain on a schedule when churn behavior shifts.
- Track F1, recall, precision, and calibration before changing the default classification threshold.
